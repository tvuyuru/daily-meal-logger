+ Log a Meal

Welcome to my Daily Meal Logger. I started this site last week as a way to keep track of what I eat each day. The idea is simple: write down my meals so I can start noticing patterns, like whether I'm skipping meals or eating the same few things too often.

On this site you'll find three other pages you can explore: Log a Meal, where you record what you ate; Healthy Tips, with small habits worth trying; and About, where you can read the story behind why this app exists. Feel free to click through and see how it's set up so far.

This is an early version of the app, built as a class project and still growing. Want to know the story behind why I built it in the first place? Check out the About page.
